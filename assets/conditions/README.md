# Treatment card banner photos

Drop a real photo here for any condition and it appears automatically on that
card on the home page (the calming coloured banner is only a fallback shown when
the photo is missing).

**Use exactly these file names** (all lowercase, `.jpg`):

| File name             | Card                     | Suggested calming photo |
|-----------------------|--------------------------|--------------------------|
| `skin.jpg`            | Skin Diseases & Vitiligo | Clear, healthy skin / person smiling |
| `allergies.jpg`       | Allergies                | Fresh outdoors, flowers, breathing easy |
| `migraine.jpg`        | Migraine                 | Calm, relaxed person, peaceful |
| `pcod.jpg`            | PCOD                     | Confident, healthy woman / wellness |
| `kidney-stones.jpg`   | Kidney Stones            | Glass of water / hydration |
| `acidity.jpg`         | Acidity & Digestion      | Fresh healthy food / greens |
| `paediatric.jpg`      | Paediatric Illnesses     | Happy, healthy child |
| `mental-health.jpg`   | Mental Health Care       | Calm, meditation, peace of mind |

### Homepage galleries
Some conditions also show a photo **gallery** on the home page (it appears
automatically once at least one photo is uploaded):

| Gallery              | File names |
|----------------------|------------|
| Skin & Vitiligo      | `skin.jpg`, `skin-2.jpg`, `skin-3.jpg`, `skin-4.jpg`, `skin-5.jpg` |
| Allergies            | `allergies.jpg`, `allergies-2.jpg`, `allergies-3.jpg` |

(`skin.jpg` / `allergies.jpg` are shared with the treatment-card banner.)

### Tips
- **Size:** roughly **800 × 500 px** (landscape). Anything close is fine — the
  card crops to fit.
- **Format:** `.jpg` (or rename a `.png`/`.jpeg` to `.jpg`).
- **Licence:** use your own clinic photos, or genuinely free-to-use images
  (e.g. Pexels / Unsplash / Pixabay — all free for commercial use). Please don't
  use random photos from Google, to stay clear of copyright.
- Add them, commit, and push — they go live within a minute. No code change needed.
